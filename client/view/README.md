# CivicConnect View Directory (`client/view/`)

This folder contains architectural notes, layout specifications, and visual assets related to the **CivicConnect** frontend interface.

### Contents:
- **`../view.md`**: Master blueprint describing the entire frontend architecture, execution flow, component tree, and technology choices.
- **Components Reference**:
  - `HeroMapWidget.jsx`: Vector & satellite map display with live GPS tracking.
  - `RecentIssuesSection.jsx`: Live grid displaying recently reported civic issues.
  - `BeforeAfterSlider.jsx`: Split-view image comparison showing proof-of-fix verification.
  - `MapPicker.jsx`: Coordinate selector for citizens reporting issues.
  - `OfficialAuditReport.jsx`: Audit dossier for verified civic resolutions.
  - `AiAnalysisDemo.jsx`: Interactive walkthrough of Google Gemini Vision detection.
